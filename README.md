# Preguntas de Reflexión

## ¿Cuál es la diferencia entre un método normal y uno static?

Un método normal requiere crear un objeto para utilizarlo, mientras que un método static puede ejecutarse directamente desde la clase sin crear una instancia.

---

## ¿En qué casos usarías sobrecarga de métodos?

La sobrecarga de métodos se utiliza cuando una misma operación necesita trabajar con diferentes cantidades o tipos de parámetros.
